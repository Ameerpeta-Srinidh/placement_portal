Phase 7 — UI Polish & Validation
7.1  Backend Validation (do this before JS)
Validation must happen server-side. This is the primary mechanism required by the project spec (JS is not to be used for core requirements).

Email format check: use a simple regex or check for '@' and '.'
CGPA must be between 0.0 and 10.0
Password must be at least 8 characters
Deadline must be a future date
Resume must be a .pdf file under 2 MB (enforced by MAX_CONTENT_LENGTH)

7.2  HTML5 Validation (complementary)
Add HTML5 attributes directly in templates. These run client-side and improve UX without relying on JS logic for correctness.

7.3  Bootstrap Components to Use
Cards for drive listings (card-deck or row of col-md-4)
Badges for status labels: badge bg-warning / bg-success / bg-danger
Table table-striped table-hover for all tabular data
Alert alert-dismissible for flash messages (already in base.html)
Modal (Bootstrap) for confirm-before-delete prompts on admin pages
